# CLOSER

*Trigger: "close this out" / end of any deciding or aligning loop*
*Behavioral signal: Loop has generated and stress-tested options and something needs to land — no open resolution*
*Auto-shift: No — called explicitly at loop exit*
*Confirm before load: No*
*Exit: Close artifact produced — return to DEFAULT*

---

## What it is

Terminal convergence gear. Fires at the end of a loop when options have been generated, stress-tested, or debated — and something needs to land. Not a summary. Not a recap. A committed direction with a next action. Always produces an artifact. Never produces a non-close — if unresolved, becomes a conditional close.

---

## How to run

1. **Confirm loop completion** — verify options were generated and stress-tested, not just listed
2. **Read the room** — clean close or conditional? Name what's still unresolved, if anything
3. **Lock the decision** — one direction, stated without hedge
4. **Name the next action** — owner, deliverable, timeframe if known
5. **Scale the artifact** — micro, standard, or conditional based on decision weight
6. **Deliver and return** — artifact produced → back to DEFAULT

---

## Output types

- **Clean close:** Decision made, path clear. "Decision: X. Next: Y. By: Z."
- **Conditional close:** Decision made, one assumption must hold.

## Artifact scale

- Micro: `Decision: [X] / Next: [Y]`
- Standard: adds Owner + By
- Conditional: adds Condition + branching next

---

## When to use / When not to use

**Use:** At the end of a deciding or aligning loop, when options have been stress-tested and something needs to land. When the session needs a committed direction, not a summary. PITCH loop stage 3 — building the ask.

**Not:** Mid-loop while options are still being generated. Not a substitute for BRIEF (BRIEF frames incoming context; CLOSER closes outgoing decisions). Not when ambiguity is genuine — use the conditional close format rather than forcing a clean close.

**False-positive risk:** Using CLOSER to summarize instead of close. If the artifact reads "here's what we covered" rather than "here's what we decided and what's next," that's a recap, not a close.

---

## Negative parameters

- Not a summary — summaries recap, CLOSER commits
- Not a decision log — one direction, not a list of what was considered
- Not a next-steps list — one next action, not a project plan
- Never produces a non-close — if genuinely unresolved, make it conditional, not inconclusive
- Artifact must be scannable in under 10 seconds — if longer, it's a document, not a CLOSER artifact

## Notes

- NOT a summary. Summaries recap. CLOSER commits.
- Can be used to close any session segment — not just formal loops
