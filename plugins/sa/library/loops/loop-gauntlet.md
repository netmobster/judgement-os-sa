# GAUNTLET

*Invoke: "Run the Gauntlet" / "Gauntlet this"*
*Chain: WHITEBOARD (brainstorm pass) → PRESSURE TEST → DEFAULT*

## WHAT IT IS

Generate then destroy. Brainstorm freely, then run PRESSURE TEST on everything that was generated. What survives PRESSURE TEST is the real product. More aggressive than FORGE — FORGE stress-tests, GAUNTLET tries to kill.

## CHAIN

1. WHITEBOARD (brainstorm pass) — Generate options without judgment. Quantity over quality. Get everything on the table. Don't evaluate — that's Stage 2's job.
	*Advance when: the full range of options is visible — nothing more to add without strain. Minimum confidence: provisional.*
2. PRESSURE TEST — Full adversarial run on all generated options. Not stress-testing — actively trying to destroy each one. Trap options, wrong-answer provocations, the full adversarial pass. Exit via DEBRIEF.
	*Advance when: every option from Stage 1 has been put under genuine pressure and classified. Minimum confidence: high.*
3. DEFAULT — Execute on survivors. DEBRIEF handles Casualties and Survivors — DEFAULT picks up from there.

## EXIT

GAUNTLET exits through DEBRIEF — Casualties and Survivors catalogue what died and what held, then returns to DEFAULT for execution. Don't skip it.

## Loop exit

A completed Casualties list, a clear Survivors list, and an execution path. Every option generated in Stage 1 has been classified — dead or alive — and the reasoning is on the table. What you hold when it's done: the options that survived genuine adversarial pressure, not just the ones that felt strong before being tested.

## WHEN TO USE

- High-stakes decision with multiple options and you need to know which ones are real
- Emotionally attached to an idea and need it genuinely tested before committing
- "I have five options and I need to know which ones are bullshit"

## WHEN NOT TO USE

- The idea is small — FORGE is cheaper
- You need to build, not evaluate — FORGE or ARCHITECT
- You're depleted — GAUNTLET requires genuine engagement. Schedule it for when you can fight back.
- You already know the answer and want GAUNTLET to ratify it — that's not testing, it's theater
