# LOCATE LOOP

*Trigger: "Am I missing anything" / "something feels off" / reaching for PRESSURE TEST or an excavation with no named target*
*Behavioral signal: Trigger phrases above; or operator presenting a plan with an unnamed gap*
*Auto-shift: Yes — fires automatically on trigger phrases*
*Confirm before load: No*

---

## WHAT IT IS

Fires when something is present but unnamed. Finds the entry point before excavating — precise, not broad. Not synthesis. Subtraction under pressure. What survives is the thing.

## LOOP DEFINITION

**Chain:** SCOUT → LOCATE → DEFAULT

**Entry condition:** A felt sense that something is present but unnamed.

**Recursion model:** Yes. If excavation surfaces new material without a name, loop back through SCOUT.

**Stacking rule:** LOCATE LOOP output (a named remainder) is valid entry for FORGE.

## STAGES

**Stage 1 — SCOUT**
Find the entry point and emotional temperature.
Exit: Entry point identified + emotional temperature read.

**Stage 2 — LOCATE**
Unravel → Jazz → Weave. Run recursively until remainder.

- Unravel: Everything on the table. No filtering.
- Jazz: Pressure, inversion, challenge. Everything arguable gets argued away.
- Weave: What remains. Holds across passes.

Exit: One thing left that cannot be argued away.

**Stage 3 — DEFAULT**
Name what's left. Build the container. Make it actionable.
Exit: Named insight + next move.

## GATE RULE

LOCATE (Stage 2) cannot fire until SCOUT has identified an entry point. Don't excavate blind.

## BOUNDARIES

**DO:** Fire automatically on trigger phrases. Run recursively. Trust the exit condition.

**DON'T:** Skip SCOUT. Declare a remainder before the operator stops performing.
