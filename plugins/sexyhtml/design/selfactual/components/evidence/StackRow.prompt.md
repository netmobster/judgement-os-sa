The stack row — "these all swap, this one stays." A list of StackRows closed by one with `keep`.

```jsx
<StackRow label="Intelligence" verb="Swap the model" items={[<>Claude · Copilot <EvidenceTag state="shipped" /></>, <>Gemini <EvidenceTag state="hypothesis" /></>]} />
<StackRow keep label="Operator layer" verb="Don't swap this">State · profile · judgment · ledger. <b>Yours. Constant.</b></StackRow>
```

Use instead of a table whenever the content is a swap list with one invariant.
