Button — 13px/700 uppercase Source Sans, square. Primary is gold with an 8px chamfer and a bevel; secondary is a raised white surface; ghost is steel text.

```jsx
<Button>Copy text</Button>
<Button variant="secondary">Open link</Button>
<Button variant="ghost">See more</Button>
<Button size="sm">Run</Button>
```

Verbs with objects. One primary per block. Hover brightens the gold; press darkens it with an inset shade.
