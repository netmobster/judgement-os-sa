Comparison — two raised panels; the chosen one gets gold corner brackets and gold labels.

```jsx
<Comparison chosen={1} sides={[
  { label: 'A // Before', title: 'The old way', body: 'What it was, and the count that mattered.' },
  { label: 'B // After', title: 'The new way', body: 'What changed, and the count that decided it.' },
]} />
```

Use stack for long bodies. State the count that decided it in the body.
