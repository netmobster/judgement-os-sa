Readout — the recessed, scan-lined mono strip: SYS.ECHO // 14:02:33, then the artifact's own values.

```jsx
<Readout items={[{ text: 'SYS.ECHO', dot: true }, { text: clock, live: true }, 'Value']} end="YYYY.MM.DD" />
```

Only genuinely live values get live (gold, pulsing). Uppercase comes from CSS; write the text as you want it read.
